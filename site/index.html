Free 3D assets for your agent

An MCP server. Your agent asks for "a wooden chair, 0.8 m" and gets a GLB URL, the real size in metres, the licence and a credit line it can paste into the project.

{{ASSETS}}assets searchable
{{GLB}}with a ready GLB
{{SOURCES}}libraries and packs

Add it

Claude Code:

claude mcp add --transport http free-3d-assets https://assets.codepawl.com/mcp

Any client that takes a JSON config (Cursor, Claude Desktop, VS Code):

{ "mcpServers": { "free-3d-assets": { "url": "https://assets.codepawl.com/mcp" } } }

Or run it on your own machine, no server needed:

claude mcp add free-3d-assets -- npx -y github:codepawl/asset-gate

Tools

  • search_assets: plain words plus filters for kind, licence, size, style, rigged and source.
  • get_asset: GLB URL in every tier, size, licence and credit line.
  • list_sources: what is searched and under which licence.
  • find_elsewhere: search links for other free libraries when nothing fits.

Where the files come from

GLB packs on Hugging Face (Amazon Berkeley Objects, NVIDIA SimReady, Google Scanned Objects, Smithsonian, NASA, Objaverse, Google Poly, PLATEAU cities, Mars terrain, robots and more), plus Poly Haven, ambientCG, Kenney and Quaternius. Megascans listings are links only: Fab licenses them to each user.

Files download straight from Hugging Face and Poly Haven. Plain JSON works too: /api/search?q=wooden chair.
