Free 3D assets for your agent

One MCP server. Your agent asks for "a wooden chair, 0.8 m" and gets a GLB it can load, the real size in metres, the licence and a credit line to paste.

{{ASSETS}} models, materials and HDRIs {{GLB}} ready GLBs {{SOURCES}} sources Free, no key

Four tools

search_assets

Plain words plus filters for kind, licence, size, style, rigged and source. "rock 2 m" filters by size on its own.

get_asset

The GLB URL in every tier, the decoders each needs, a three.js load snippet, the size, the licence and the credit line.

list_sources

Every library and pack, with counts, licences and how each one is scaled.

find_elsewhere

Search links for other free libraries when nothing here fits.

Where the files come from

Files load straight from Hugging Face and Poly Haven; this server only searches and redirects. Megascans entries are links only, because Fab licenses them to each user. The same search answers as plain JSON: /api/search?q=wooden chair.
